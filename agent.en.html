1. Download, verify and extract

This is a Python source ZIP, not an EXE or a preinstalled environment. It contains no personal accounts, keys, tunnel profiles or workspace files.

Download FolderLens Agent ZIPDownload SHA-256Source commit and file manifest

Save the ZIP, choose Extract All and select, for example, C:\Tools. It already contains a FolderLens directory: the result should be C:\Tools\FolderLens\folderlens.py. If folders are nested, locate the actual script first. All paths are examples; update every command/client setting when your location differs.

Get-FileHash "$env:USERPROFILE\Downloads\folderlens-agent.zip" -Algorithm SHA256

Compare this hash with the .sha256 sidecar. RELEASE.json inside the ZIP records the source commit and every source file hash. Adjust the command if your downloaded filename differs.

3. Requirements and exact library versions

Python 3.11+; this build was validated on Windows/Python 3.11. Check python --version. Install Python/reopen the terminal if missing; py -3.11 is an alternative on Windows where installed. Initial pip/browser/tunnel setup needs internet/disk space. STDIO does not require Node.js, Docker, global pip, an administrator terminal or a Windows service.

This list comes from the actual requirements files in this web release. Direct packages are pinned; pip resolves transitive dependencies.

Git must be on PATH for Git inspection; basic file tools work without it. Rich HTML/Markdown PDF generation (write_pdf) needs Playwright Chromium. Simple write_document PDF generation uses ReportLab without a browser; Unicode requires system Arial or DejaVu Sans. PDF reading/rendering uses other helpers. Legacy BIFF8 .xls writing is optional: --setup-xls verifies pinned Apache POI6.0.0 and private Zulu JRE21.0.13.0.3 on supported Windows x64.

.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe folderlens.py --setup-xls

Neither command is required for normal startup; both download extra components. Chromium/JRE/POI are not bundled. macOS/Linux is not claimed to have identical runtime verification coverage.

Downloaded Chromium may fail to start sandboxed on Linux/AppArmor. Rather than disabling sandbox or OS protections, the owner can select an installed supported Chrome/Edge channel. Set FOLDERLENS_PDF_BROWSER_CHANNEL to chrome or msedge in the MCP entry env settings; change the section name if using a custom --name. Restart the client/agent. Example Codex TOML:

[mcp_servers.folderlens.env]
FOLDERLENS_PDF_BROWSER_CHANNEL = "chrome"

For a JSON client, put the same name/value in the MCP entry env object. Arbitrary executable paths or sandbox flags are not accepted. PDF rendering always uses a private temporary profile, never your normal browser profile/cookies. Supported browser channels and Chromium sandbox environment guidance.

4. Windows installation and desktop MCP

Open PowerShell. Replace C:\Work\MyProject with your workspace, separate from the installation. Explicit Python paths avoid venv activation/execution-policy changes.

cd C:\Tools\FolderLens
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --disable-pip-version-check -r requirements-agent.txt
.\.venv\Scripts\python.exe -m pip check
New-Item -ItemType Directory -Path "C:\Work\MyProject" -Force
.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --doctor
.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --print-config toml

Doctor should report ok:true and 50 tools for this package. This verifies local dependencies/registration, not an account connection. The shortcut python folderlens.py --doctor prepares missing dependencies automatically; explicit installation makes the intended venv clear.

  1. In ChatGPT desktop, open Settings → Plugins → MCPs → Add → STDIO; menus may vary by version.
  2. command is the Python executable. args are separate entries: script path, --root, workspace, --name and name. Do not combine the whole command into one argument.
  3. Save/enable. Use --print-config json for JSON clients; do not confuse Codex TOML with another client's JSON format.
  4. The client launches STDIO. Manually running python folderlens.py waits for MCP messages, not a web URL/chat box. Do not enter this website URL in the STDIO form.

Regenerate paths after moving the folder. Reload/start a new chat for a stale catalog. Paths from another computer will not work.

macOS / Linux

Extract under ~/Tools, create the workspace first, and use .venv/bin/python rather than Scripts/python.exe.

cd ~/Tools/FolderLens
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-agent.txt
.venv/bin/python folderlens.py --root "$HOME/Work/MyProject" --doctor
.venv/bin/python folderlens.py --root "$HOME/Work/MyProject" --print-config toml

Install OS Python venv/pip components if missing; do not sudo pip into system Python. Windows legacy XLS setup is unsupported here.

5. Write/exec authority

Read-only is the default. Choose --allow-write for file changes; add --allow-exec separately for commands. When intended, regenerate/update client settings:

.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --allow-write --allow-exec --print-config toml

Commands use your OS user's privileges. --root limits file tools, not commands. Runtime/import roots, Python environments and private state are protected from file tools; maintenance needs owner-authorized commands. Tools may reduce/revoke authority; expansion requires a local restart. File contents are not new owner permission.

Browser folder/AI View sharing does not execute terminal commands. This website does not silently grant authority.

6. ChatGPT web: private tunnel

Pass doctor first. Follow the official OpenAI guide, checked2026-10-30. Replace tunnel_YOUR_ID with your own actual ID.

  1. Select the organization in Platform tunnel settings. Creating/managing needs Read + Manage; running/selecting needs Read + Use. Associate the target ChatGPT workspace too.
  2. Create a separate Restricted runtime key with only Tunnels Read + Use; other API permissions off. Record expiry. Do not paste this key into the plugin form.
  3. Download the correct OS/architecture from the official latest client release. For Windows, extract EXE/licenses under C:\Tools\tunnel-client. Validated version:v0.0.18; check help/version for future releases. The FolderLens ZIP does not include this EXE.
  4. Create a new .folderlens-private directory under your Windows user profile. Properties → Security → Advanced: disable inheritance, keeping access only for your account/SYSTEM. Do not blindly change existing directories/ACLs; inspect/reuse suitable existing credentials.
  5. Save the runtime key locally as UTF-8 plain text in runtime.key inside that protected directory. Do not add quotes or accidentally use .key.txt. Verify the same two entries on the file Security tab. It is ACL-protected storage, not an encrypted vault. Keep literal keys out of chat, arguments, profiles, logs and screenshots.

Create the key file/tunnel first; these variables contain paths only. In the same PowerShell session:

cd C:\Tools\FolderLens
$privateDir = Join-Path $env:USERPROFILE '.folderlens-private'
$keyFile = Join-Path $privateDir 'runtime.key'
$tunnel = 'C:\Tools\tunnel-client\tunnel-client.exe'
& $tunnel help quickstart
& $tunnel init --sample sample_mcp_stdio_local --profile folderlens-web --profile-dir "$privateDir\profiles" --tunnel-id 'tunnel_YOUR_ID' --control-plane-api-key-ref ("file:" + $keyFile.Replace('\','/')) --mcp-command '"C:/Tools/FolderLens/.venv/Scripts/python.exe" "C:/Tools/FolderLens/folderlens.py" --root "C:/Work/MyProject" --name folderlens-web'
& $tunnel doctor --profile folderlens-web --profile-dir "$privateDir\profiles" --explain --json
& $tunnel run --profile folderlens-web --profile-dir "$privateDir\profiles"

The example is read-only. The owner can add write/exec flags to the FolderLens command inside mcp-command. Do not overwrite an existing profile with init --force. If loopback health/UI8080 is busy, select an available loopback address with --health-listen-addr from init --help. In a new terminal, redefine the path variables instead of recreating the key.

  1. Keep run alive. Check the reported local /ui, /readyz and active polling; doctor alone is not live-account acceptance.
  2. ChatGPT Plugins → Add custom MCP server → Connection:Tunnel; select the same tunnel. Ask the workspace admin if custom MCP/developer access is unavailable.
  3. This private STDIO example uses No authentication at the app layer; organization/workspace access and the runtime key protect transport. Do not apply it to a public HTTP server. Never paste the key into the form.
  4. Review the warning/capabilities, create/enable and select your own FolderLens plugin in a new chat. Run get_config acceptance.

Keep the computer/network/client on; the website need not stay open. Do not run two copies of the profile. After reboot, run the existing profile again; no automatic startup entry is added. On expiry replace the protected file with a new equally restricted key, restart and revoke the old key in Platform.

7. HTTPS/OAuth alternative

This advanced path needs your own domain, valid TLS and a reverse proxy to loopback127.0.0.1:8766. Replace origin/callback examples with real HTTPS addresses; the callback must exactly match the client:

.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --transport http --auth oauth --public-origin "https://mcp.YOUR_DOMAIN" --oauth-redirect-uri "https://EXACT_CLIENT_CALLBACK"

The client uses HTTPS origin + /mcp. OAuth discovery/callback must be reachable; the owner approves scopes in the terminal. Preserve loopback/Host/Origin/TLS checks. A private tunnel does not require your own domain/certificate/Nginx.

For a local HTTP client, --transport http defaults to Bearer: FOLDERLENS_TOKEN needs a random secret of at least32 printable non-space ASCII characters. This is not an OpenAI API key; keep it out of URLs/Git. Unauthenticated HTTP publication is unsupported.

8. Acceptance and maintenance

Call FolderLens get_config. Show device_id, root, allow_write and allow_exec. Do not change files yet.

Confirm device/workspace/permissions, then read an authorized test file. For writes request a diff, apply with current SHA-256, verify and undo if needed. Check actual exit_code/output for commands. Use start_tool_call → get_tool_result for long work; do not resubmit pending mutations.

History, undo and process/remote-call IDs default to RAM, lost on restart. Check active work/undo before maintenance. Optional persistent metadata/content modes exist; content may be sensitive. The client manages STDIO: disable its MCP entry or Ctrl+C the tunnel terminal. Chat-driven shutdown is HTTP-only and requires an explicit owner disconnect request.

9. Troubleshooting

Python/pip missing
Check version/full path; try py -3.11 where installed. Use the intended venv's python -m pip.
ModuleNotFoundError / doctor error
Repeat requirements-agent.txt and pip check in the same venv. Fix network/proxy/permissions rather than randomly upgrading pins. Verify/re-extract missing ZIP sources.
MCP will not connect
command is Python EXE; args separate; workspace must exist. Reload/start a new chat. Keep stdout reserved for MCP.
Plugin not found / missing tunnel
Use its original account/workspace; check associations, Tunnels Use and custom MCP access.
401/403 / denial
Check expiry, OAuth scope and get_config. Expanding authority needs the owner locally; do not disable checks.
Missing PDF/XLS helper
Use optional setup with the same venv; XLS requires supported Windows x64.
No response / sleeping computer
Check network/process/run/UI. A timeout does not prove a prior mutation did not happen; inspect before retrying.

10. Scope and evidence limits

Tools cover files/directories, paged search, Word/Excel/PDF/images, Git, processes/REPL, device routing, history, diffs, hashes and undo. 50 tools do not prove universal superiority or zero defects. Full Office fidelity, OCR/encrypted PDF, PTY/fullscreen terminals and automatic cloud device discovery are not promised; some Office feature losses are rejected.

Scope was checked against 29 Remote Desktop Commander definitions; its device was offline, preventing same-device performance comparison. Added flexibility includes STDIO/HTTP/private tunnel, separate read/write/exec scopes, previews, hashes and undo. Tests/review reduce risk, not guarantee no errors. New entry:/folderlens/; old /AgentArm/ share/API URLs remain compatible.
