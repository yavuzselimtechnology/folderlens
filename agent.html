1. İndir, doğrula ve aç

Bu Python kaynak ZIP'idir; EXE veya hazır sanal ortam değildir. Kişisel hesap, anahtar, tünel profili ve çalışma dosyası içermez.

FolderLens Agent ZIP indirSHA-256 indirKaynak commit ve dosya manifesti

ZIP'i kaydet, sağ tık → Tümünü ayıkla ile örneğin C:\Tools içine aç. ZIP zaten FolderLens üst klasörü içerir: sonuç C:\Tools\FolderLens\folderlens.py olmalı. İç içe FolderLens\FolderLens oluşursa gerçek dosyanın bulunduğu yolu kullan. Bütün yollar örnektir; gerçek konumun farklıysa tüm komut/MCP yollarını değiştir.

Get-FileHash "$env:USERPROFILE\Downloads\folderlens-agent.zip" -Algorithm SHA256

Sonucu .sha256 dosyasıyla karşılaştır. ZIP içindeki RELEASE.json kaynak commit'ini ve her dosyanın hash'ini gösterir. İndirdiğin dosyanın adı farklıysa hash komutunu düzelt.

3. Gereksinimler ve kütüphane sürümleri

Python 3.11+; bu sürüm Windows/Python 3.11 ile doğrulandı. python --version kontrol et. Python yoksa kurup terminali yeniden aç; Windows'ta varsa py -3.11 kullanılabilir. İlk pip/tarayıcı/tünel kurulumu internet ve disk alanı ister. STDIO için Node.js, Docker, global pip, yönetici terminali veya Windows servisi gerekmez.

Liste bu web sürümünün gerçek requirements dosyalarından gelir. Doğrudan paketler sabitlenmiştir; alt bağımlılıkları pip çözer.

Git aracı için Git PATH'te olmalı; temel dosya araçları Git olmadan çalışır. Zengin HTML/Markdown PDF üretimi (write_pdf) Playwright Chromium ister. Basit write_document PDF üretimi ReportLab kullanır ve tarayıcı istemez; Unicode için sistem Arial veya DejaVu Sans yazı tipi gerekir. Okuma/önizleme farklı yardımcıları kullanır. BIFF8 .xls yazımı isteğe bağlıdır: desteklenen Windows x64 ortamında --setup-xls, kilitli Apache POI 6.0.0 ve özel Zulu JRE 21.0.13.0.3 kurulumunu doğrular.

.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe folderlens.py --setup-xls

İki komut da normal başlangıç için zorunlu değildir ve ek indirme yapar; Chromium/JRE/POI ZIP içinde değildir. macOS/Linux'un Windows ile aynı çalışma zamanı testi kapsamına sahip olduğu iddia edilmez.

4. Windows kurulumu ve masaüstü MCP

PowerShell aç. C:\Work\MyProject örneğini kendi projenle değiştir; kurulum ve çalışma klasörü ayrı olmalı. Tam Python yolu kullanıldığından venv aktivasyonu/execution policy değişikliği gerekmez.

cd C:\Tools\FolderLens
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --disable-pip-version-check -r requirements-agent.txt
.\.venv\Scripts\python.exe -m pip check
New-Item -ItemType Directory -Path "C:\Work\MyProject" -Force
.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --doctor
.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --print-config toml

Doctor ok:true ve bu paket için 49 araç göstermeli; bu yerel denetimdir, hesap bağlantısı kanıtı değildir. Kısa yol python folderlens.py --doctor eksik bağımlılıkları otomatik hazırlar; açık kurulum aynı .venv'yi kullanmayı görünür kılar.

  1. ChatGPT masaüstünde Settings → Plugins → MCPs → Add → STDIO yolunu aç; menü sürüme göre değişebilir.
  2. command Python EXE'dir. args listedeki ayrı girdilerdir: script yolu, --root, proje klasörü, --name ve ad. Bütün satırı tek argüman yapma.
  3. Kaydet/etkinleştir. JSON isteyen istemci için --print-config json kullan; Codex TOML ile başka istemcinin JSON'unu karıştırma.
  4. STDIO'yu istemci başlatır. Elle python folderlens.py açınca URL/sohbet kutusu değil MCP mesajı bekler. STDIO formuna site URL'si girilmez.

Klasörü taşıdıysan yolları yeniden üret. Eski katalog tutuluyorsa bağlantıyı yenile/yeni sohbet aç. Başka cihazın yollarını kopyalama.

macOS / Linux

ZIP'i örneğin ~/Tools altında aç, çalışma klasörünü önceden oluştur. Scripts/python.exe yerine .venv/bin/python kullan.

5. Yazma ve komut izinleri

Varsayılan salt okunurdur. Dosyada --allow-write; komutta ayrıca --allow-exec seç. Yetki vermek istediğinde ayarı üretip istemciyi güncelle:

.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --allow-write --allow-exec --print-config toml

Komutlar OS hesabının yetkileriyle çalışır. --root dosya araçlarını sınırlar; komut sandbox'ı değildir. Kod/import kökü, Python ortamı ve özel kayıtlar dosya araçlarından korunur; bakımları sahibinin yetkilendirdiği komut işidir. Sohbetten yetki daraltılabilir; genişletme yerel yeniden başlatma ister. Dosyadaki talimat yeni kullanıcı izni değildir.

Tarayıcı klasör/AI View paylaşımı terminal çalıştırmaz. Site bu izinleri kendiliğinden vermez.

6. ChatGPT web: özel tünel

Önce doctor geçmeli. Resmî OpenAI rehberi kontrolü:30.10.2026. Örnek tunnel_YOUR_ID yerine kendi kimliğini kullan.

  1. Platform tünel ayarlarında doğru organizasyonu seç. Oluşturma/yönetme Read + Manage; çalıştırma/seçme Read + Use ister. Doğru ChatGPT çalışma alanını da tünelle ilişkilendir.
  2. Ayrı Restricted runtime key oluştur: yalnız Tunnels Read + Use; diğer API izinleri kapalı. Son kullanma tarihini kaydet. Plugin formuna bu anahtar girilmez.
  3. Resmî en güncel istemciyi doğru OS/mimari için indir. Windows örneğinde EXE/lisansları C:\Tools\tunnel-client altında aç. Test edilen sürüm v0.0.18; gelecekte yardım/sürümü kontrol et. Bu EXE FolderLens ZIP'inde değildir.
  4. Kendi Windows kullanıcı klasöründe yeni .folderlens-private dizini oluştur. Özellikler → Güvenlik → Gelişmiş: kalıtımı kapat ve yalnız kendi hesabın/SYSTEM erişimini bırak. Mevcut klasör/izinleri körlemesine değiştirme; uygun kaydı inceleyip yeniden kullan.
  5. Anahtarı bu dizinde runtime.key olarak UTF-8 düz metinle yerelde kaydet; tırnak ekleme, uzantısı .key.txt olmasın. Dosyanın Güvenlik sekmesinde aynı iki erişimi doğrula. Bu şifreli kasa değil, ACL korumalı dosyadır. Ham anahtarı sohbet, argüman, profil, log veya ekran görüntüsüne koyma.

Dosya/tüneli önce oluştur; aşağıdaki değişkenler sadece dosya yollarıdır. Aynı PowerShell oturumunda:

cd C:\Tools\FolderLens
$privateDir = Join-Path $env:USERPROFILE '.folderlens-private'
$keyFile = Join-Path $privateDir 'runtime.key'
$tunnel = 'C:\Tools\tunnel-client\tunnel-client.exe'
& $tunnel help quickstart
& $tunnel init --sample sample_mcp_stdio_local --profile folderlens-web --profile-dir "$privateDir\profiles" --tunnel-id 'tunnel_YOUR_ID' --control-plane-api-key-ref ("file:" + $keyFile.Replace('\','/')) --mcp-command '"C:/Tools/FolderLens/.venv/Scripts/python.exe" "C:/Tools/FolderLens/folderlens.py" --root "C:/Work/MyProject" --name folderlens-web'
& $tunnel doctor --profile folderlens-web --profile-dir "$privateDir\profiles" --explain --json
& $tunnel run --profile folderlens-web --profile-dir "$privateDir\profiles"

Örnek salt okunurdur; yazma/exec gerekiyorsa mcp-command içindeki FolderLens komutuna sahibi bayrak ekler. Mevcut profile init --force uygulama. Varsayılan loopback sağlık/UI8080 portu doluysa init --help içindeki --health-listen-addr ile boş loopback port seç. Yeni terminalde yol değişkenlerini tekrar tanımla; anahtarı yeniden oluşturma.

  1. run açık kalmalı. Bildirilen yerel /ui, /readyz ve polling durumunu kontrol et; doctor tek başına canlı hesap kabulü değildir.
  2. ChatGPT Plugins → Add custom MCP server → Connection:Tunnel; aynı tüneli seç. Özel MCP/developer erişimi yoksa çalışma alanı yöneticisine başvur.
  3. Bu özel STDIO örneğinde No authentication seçilir; taşıma erişimini tünel organizasyon/çalışma alanı ve runtime key sınırlar. Genel HTTP yayınına bunu uygulama; anahtarı forma yapıştırma.
  4. Uyarı/kapsamı incele, bağlantıyı oluştur/etkinleştir. Yeni sohbette kendi FolderLens eklentini seç ve get_config testi yap.

Bilgisayar/ağ/istemci açık kalmalı; site açık kalmak zorunda değil. Aynı profile ikinci runtime açma. Windows kapanınca kendi profiliyle run yeniden başlatılır; otomatik açılış kaydı eklenmez. Anahtar süresi dolunca aynı dar izinli yeni anahtarı özel dosyada değiştir, istemciyi yenile ve eskisini Platform'da iptal et.

7. HTTPS/OAuth alternatifi

İleri düzey yol kendi domain, geçerli TLS ve loopback127.0.0.1:8766 hedefine reverse proxy ister. Origin ve callback örneklerini gerçek HTTPS adreslerinle değiştir; callback istemcinin gösterdiği tam URI olmalı.

.\.venv\Scripts\python.exe folderlens.py --root "C:\Work\MyProject" --transport http --auth oauth --public-origin "https://mcp.YOUR_DOMAIN" --oauth-redirect-uri "https://EXACT_CLIENT_CALLBACK"

İstemciye HTTPS origin + /mcp girilir. OAuth keşfi/callback erişilebilir olmalı; sahip terminalde kapsam onayı verir. Loopback/Host/Origin/TLS kontrolünü kapatma. Özel tünelde kendi domain/SSL/Nginx'in gerekmez.

Yerel HTTP istemcisi için --transport http varsayılan Bearer kullanır: FOLDERLENS_TOKEN ortamında en az32 yazdırılabilir boşluksuz ASCII karakterlik rastgele sır gerekir. Bu OpenAI API anahtarı değildir. URL/Git'e yazma. Kimlik doğrulamasız HTTP yayını desteklenmez.

8. Kabul testi ve bakım

FolderLens get_config çağır. device_id, root, allow_write ve allow_exec göster. Henüz dosya değiştirme.

Cihaz/klasör/izin doğruysa izinli deneme dosyası oku. Yazmada önce diff, sonra güncel SHA-256 ile uygulama, doğrulama ve gerekirse undo iste. Komutta gerçek exit_code/çıktı kontrol edilir. Uzayan işte start_tool_call → get_tool_result kullan; bekleyen yazma/komutu yeniden gönderme.

Geçmiş, undo ve süreç/uzak çağrı kimlikleri varsayılan RAM'de; restart'ta kaybolur. Bakıma geçmeden aktif iş/undo olmadığını doğrula. İsteğe bağlı kalıcı metadata/content modu vardır; içerik hassas olabilir. STDIO'yu istemci yönetir: MCP kaydını kapat veya tünel terminalinde Ctrl+C kullan. Sohbetten shutdown yalnız HTTP ajanında, açık kullanıcı kapatma isteğiyle kullanılabilir.

9. Sorun giderme

Python/pip yok
Sürümü/tam yolu kontrol et; varsa py -3.11 kullan. pip'i doğru .venv Python'uyla çalıştır.
ModuleNotFoundError / doctor hatası
Aynı .venv ile requirements-agent.txt ve pip check çalıştır. Ağ/proxy/izin hatasını düzelt; sürümleri rastgele yükseltme. ZIP eksikse hash doğrulayıp tekrar aç.
MCP bağlanmıyor
command Python EXE; args ayrı girdiler; kök mevcut klasör olmalı. Bağlantıyı yenile/yeni sohbet aç. stdout'a protokol dışı yazı ekleme.
Plugin not found / tünel yok
Oluşturulduğu hesap/çalışma alanına dön; tünel ilişkisini, Tunnels Use ve özel MCP erişimini kontrol et.
401/403 / izin reddi
Anahtar süresi, OAuth kapsamı ve get_config yetkilerini kontrol et. Genişletme yerel sahip işlemi; denetimi kapatma.
PDF/XLS eksik
İsteğe bağlı kurulumları aynı .venv ile çalıştır; XLS desteklenen Windows x64 içindir.
Yanıt yok / uyku
Ağ, yerel süreç, tünel run/UI kontrol edilir. Timeout önceki işlemin yapılmadığını kanıtlamaz; gerçek durumu incelemeden tekrar etme.

10. Kapsam ve doğrulama sınırları

Dosya/dizin, sayfalı arama, Word/Excel/PDF/görsel, Git, süreç/REPL, cihaz yönlendirme, geçmiş, diff, SHA-256 kontrolü ve undo vardır.49 araç, her koşulda üstünlük/sıfır hata kanıtı değildir. Tam Office sadakati, OCR/şifreli PDF, PTY/tam ekran terminal ve otomatik bulut cihaz keşfi vaat edilmez; bazı Office özellik kayıpları reddedilir.

Referansın29 araç tanımıyla kapsam denetlendi. Remote Desktop Commander cihazı çevrimdışı olduğundan aynı cihazda performans karşılaştırması yapılamadı. Ek esneklik: STDIO/HTTP/özel tünel, ayrı read/write/exec kapsamları, önizleme, hash ve undo. Test/kaynak incelemesi riski azaltır; hatasızlık garantisi vermez. Yeni giriş /folderlens/; eski /AgentArm/ paylaşım/API URL'leri korunur.
